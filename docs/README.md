# Thenar docs

- [build.md](./build.md) — assembly walkthrough (order PCBs, solder, flash).
- [routing.md](./routing.md) — how to take the ergogen scaffold to a
  routed PCB ready for fab. Only needed if you are routing yourself; the
  committed `thenar/routed/` PCB is the default path.

Both guides are currently LLM-drafted and unverified. Corrections welcome
once anyone has actually built or routed a Thenar.
